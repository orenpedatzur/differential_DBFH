Welcome to diff-DBFH open source repository. 
This repo is meant to allow researchers and enthusiasts to test and apply diff-DBFH algorithm in their telescopes, and as a supplementary to a manuscript 'Differential Double Blind Fourier Holography (diff-DBFH)' by O. Pedatzur and D. T. Chuss.
Please see the manuscript for details about the method, application and algorithm. 
A good place to start is the file: demo_compare_dDBFH_vs_dOTF_HWO_v5.m which will reproduce the numerical study figures published in the manuscript.
A key component of the method is the recovery of Im(A1^*.A2) from Re(A1^*.A2). The demo file for this step is: demo_cross_term_recovery_string_cut_KK_v2.m
